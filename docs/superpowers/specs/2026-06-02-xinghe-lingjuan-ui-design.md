# 叁视漫「星河灵卷」玄幻仙侠 UI 设计

**目标:** 将当前「星穹玄金」视觉补丁进一步调整为更明显的中国风玄幻仙侠界面，同时保持专业软件可用性，不改业务逻辑，不修改压缩 React 业务 bundle。

## 主题定位

主题名：**星河灵卷**。

核心意象：暗黑星河中的一张展开灵卷。画布是星河与云雾组成的创作台，节点像符箓/法器/灵卷卡片，任务进度像炼化过程，素材预览像画境窗口。

关键词：

- 暗黑星河
- 玄幻仙侠
- 灵卷 / 符箓 / 法阵
- 祥云暗纹
- 金色灵光
- 朱砂点缀
- 青紫灵气
- 高级克制

## 色彩系统

在现有黑金青紫基础上增强中式玄幻色彩：

- 深空墨黑：`#020308`
- 墨蓝面板：`#0e121d`
- 灵卷深蓝：`#171d2e`
- 古金：`#d6a85a`
- 亮金：`#f0cf86`
- 青灵光：`#5fd6ff`
- 紫灵光：`#a678ff`
- 朱砂红：`#c94b45`
- 错误朱砂亮色：`#ff7a70`

设计原则：金色只用于主行动、边框高光、运行进度；朱砂红只用于错误、警示、印章点缀；不使用大面积红金。

## 背景：暗黑星河 + 云雾灵卷

### 当前状态

已有星空和中心星云，偏科技宇宙。

### 新方向

调整为更玄幻：

- 星空保留，但亮度继续克制。
- 加入极淡云雾层，像山水烟气。
- 背景暗纹加入祥云/卷云感，用 CSS 渐变实现，不引入图片资源。
- 流星改成更少、更柔的“灵光划过”。
- 星座线更像淡淡法阵连线。
- 继续支持 `prefers-reduced-motion`。

## 节点：符箓灵卷卡片

节点从“AI 创作舱”改成“符箓 / 法器 / 灵卷卡片”：

### 默认态

- 深蓝黑卡片。
- 细金线 + 青蓝暗边。
- 四角有轻微角饰感，使用伪元素和渐变实现。
- 左侧能量脊线改为“符线”，金青渐变，像灵气流道。

### Hover 态

- 边框轻微发金青光。
- 卡片不明显位移，避免拖拽干扰。

### Selected 态

- 青紫灵光外环。
- 玄金内线。
- 角落出现极小朱砂点缀，像落印标记。

### Running 态

- 金色灵气沿边框慢速流动。
- 状态不大面积闪烁。

### Completed 态

- 短暂金色“落印”闪光。
- 可带玉青色完成气息。

### Error 态

- 朱砂红边框。
- 短促轻震。
- 错误区域更明确，但不使用刺眼红块。

## 输入框、按钮与表单

### 输入框

输入 prompt 区域要像“写入灵卷”，但中文可读性优先：

- 不强制书法字体。
- 使用系统中文字体。
- 背景使用墨色深面板。
- 边框使用淡金/青色细线。
- Focus 状态为金青细光。
- Placeholder 清晰但低调。

API Key、路径、数字参数可以继续使用等宽字体。

### 按钮

- 主按钮：像“启阵 / 生成”的古金按钮，金青渐变，文字深色。
- 次按钮：暗色描边，像玉牌/铭牌。
- 危险按钮：朱砂红边框，hover 时增强。

## 弹窗：卷轴控制面板

弹窗应像展开的控制灵卷：

- 深色遮罩 + 轻微云雾感。
- 主体深墨蓝。
- 顶部细金线。
- 边角有轻微中式角饰。
- 分组卡片使用淡金线和低透明背景。
- 保持设置页可读性，不牺牲表单布局。

## HUD：炼化任务浮符

进度 HUD 从“任务雷达”改成“炼化任务浮符”：

- 卡片像悬浮灵符。
- 顶部金青符线。
- 运行中进度条像金色灵气流动。
- 完成态为玉青灵光。
- 失败态为朱砂红。
- 百分比保持现代数字，确保可读。
- 缩略图区域像小画境窗口。

## 素材查看器：画境窗口

素材查看器从“星窗”进一步调整为“画境”：

- Lightbox 背景有淡云雾。
- 图片边框像淡金卷边。
- 文件名标签像小铭牌。
- 关闭按钮低调，不破坏画面。
- Resize 把手保留但减少科技霓虹感。
- 引导气泡改成墨底金边，不使用强紫色。

## 错误页

错误页从黑金科技面板调整为玄幻风错误面板：

- 标题仍为：`界面加载失败`
- Badge：`朱砂警示`
- 顶部使用金线 + 朱砂点。
- 错误详情保留可读性。
- 不增加复杂按钮，避免需要业务 API 支持。

## 动效原则

- 运行中才出现灵气流动。
- 选中才出现青紫灵光。
- 完成才出现短暂落印闪光。
- 错误才出现朱砂轻震。
- 背景灵光与云雾要慢、淡、少。
- 尊重 `prefers-reduced-motion`。

## 不做什么

为避免廉价国风，本版不做：

- 大面积红色。
- 大面积龙凤纹。
- 复杂传统纹样贴图。
- 到处贴印章。
- 过度书法字体。
- 过亮金色。
- 影响输入体验的装饰。

## 验证方式

完成后运行：

```bash
npm --prefix D:/sanshiman/resources/app test
npm --prefix D:/sanshiman/resources/app run build
npm --prefix D:/sanshiman/resources/app audit --audit-level=moderate
```

预期：

- 测试通过：`20 passed / 162 passed`。
- 构建通过。
- audit 为 `found 0 vulnerabilities`。
- `renderer config is missing` 仍可接受。

人工视觉检查重点：

- 是否比上一版更明显中国风。
- 是否仍然高级，不土。
- 金色和朱砂是否克制。
- 节点是否更像符箓/灵卷。
- 背景云雾是否不抢内容。
- 中文 prompt 输入是否舒适。
